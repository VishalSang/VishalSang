### 🚀 Featured Projects

**[Customer Shopping Behavior Analysis](https://github.com/VishalSang)**
Built and deployed a scalable Python-to-PostgreSQL ETL pipeline processing 3,900+ retail records across 18 variables, wrote 10+ SQL transformation queries, and delivered an interactive Power BI dashboard for stakeholder self-service — surfacing 5 actionable business recommendations.
`Python` `SQL` `PostgreSQL` `Power BI` `Git`

**[Financial Fraud Detection — SQL Analysis](https://github.com/VishalSang)**
Designed 5 advanced SQL-based analytical systems across 6.3M+ financial transaction records to detect fraud patterns and anomalies, using recursive CTEs to trace multi-step transaction chains and window functions for rolling risk monitoring.
`MySQL` `SQL`

**[Credit Card Portfolio Analytics](https://github.com/VishalSang)**
Designed a relational schema in PostgreSQL to track $57M in financial data across 667K+ client accounts segmented by risk tier, developing SQL-based KPI calculations that were adopted as the client's management information reporting standard.
`SQL` `PostgreSQL` `Power BI`

**[Collision Risk Prediction Pipeline](https://github.com/VishalSang)**
Built a Python and Jupyter Notebook data pipeline for 846+ fatal collision incidents across 12 variables for Toronto Police Service, then trained a Scikit-learn classification model to identify speeding-related collision risk, evaluated using ROC/AUC and decile analysis.
`Python` `Scikit-learn` `Pandas`
